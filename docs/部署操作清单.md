# 宠物养护站 · 上线部署操作清单（wagwise.org）

本清单是**买好域名之后**的一次性动作。前面"本地搭建、换图、改内容"都已做完，
这里只讲"怎么让它真正挂在 wagwise.org 上、被谷歌收录"。

整套流程参考了第一个站 craftfee.com 已经跑通的实战经验，照做即可。

---

## 阶段 0：买域名（在 Spaceship）

1. 登录 Spaceship 账号（1460038096@qq.com，和 craftfee 同一个账号）
2. 搜索并购买 **wagwise.org**（之前已确认未注册）
3. 费用约 **$10–13/年**，开启**自动续费**
4. 记下：域名、账号、到期日（记到养站台账）

> 经验：海外服务注册/验证用 **QQ 邮箱或 Gmail**，别用 189 邮箱（收不到国际验证信）。

---

## 阶段 1：DNS 切到 Cloudflare

1. 在 Cloudflare 添加站点 `wagwise.org`
2. 按提示把域名的 Nameserver 改成 Cloudflare 给的两个（去 Spaceship 后台改 NS）
3. 等 DNS 生效（几分钟到几小时，Cloudflare 会提示"有效"）

---

## 阶段 2：本地一键替换占位符 —— ✅ 已提前完成（2026-10-15）

域名已直接在源码 `build/render.py` 顶部常量 `PLACEHOLDER = "wagwise.org"` 写死，
并重新生成了全站（155 处已全部是 `wagwise.org`，`your-domain.com` 残留 0）。
所以这一步**已跳过**，你不需要再跑 set-domain.py。

- 验证： `python set-domain.py` 应显示"没有发现占位符 your-domain.com"。
- **将来若改用其他域名**（比如临时换名）：编辑 `build/render.py` 顶部的
  `PLACEHOLDER = "wagwise.org"` 改成新域名，保存后跑 `python build/render.py` 重新生成即可。
  （旧的 `set-domain.py` 脚本仅在历史文件残留 `your-domain.com` 占位符时才有用，现可忽略。）

> 说明：把域名写进源码常量，能保证你以后改文章、换图片、重跑 render.py 时，
> 全站永远一致地指向 wagwise.org，不会哪次重新生成又冒出占位符。

---

## 阶段 3：推到 GitHub

（首次需要建仓库，参考 craftfee 的做法：GitHub 网页建 `pet-care-site` Public 仓库，
main 分支）

```sh
cd pet-care-site
git add -A
git commit -m "wagwise.org initial launch"
git push origin main
```

> ⚠️ **本机推送必须用代理端口 7890**（不是 58042，那个是死端口）：
> ```sh
> export http_proxy=http://127.0.0.1:7890 https_proxy=http://127.0.0.1:7890
> git push origin main
> ```
> 判断成功要用 `git fetch origin && git log origin/main -1`，
> 不要只看 `git push` 的退出码（会被 tail 误导成假成功）。

---

## 阶段 4：Cloudflare 部署 + 绑域名

1. 在 Cloudflare 建 **Workers / 静态资源** 项目，关联 GitHub 的 `pet-care-site` 仓库
2. 构建设置（和 craftfee 一致）：
   - Build command：**留空**
   - Deploy command： `npx wrangler deploy`
   - 根目录： `/`（即仓库根，站点文件在 `public/`，由 `wrangler.jsonc` 指定）
   - `workers_dev=true`、`html_handling=auto-trailing-slash`、`not_found_handling=404-page`
3. 部署成功后，在设置里 **Custom Domain** 绑定 `wagwise.org`
4. 等几分钟，浏览器打开 `https://wagwise.org` 应正常（全球可访问）

---

## 阶段 5：谷歌收录（GSC）

1. 打开 Google Search Console，添加**网域属性** `wagwise.org`
2. 按提示验证（Cloudflare 侧加 TXT 记录，或用 DNS 验证，最稳）
3. 验证通过后，提交 sitemap： `https://wagwise.org/sitemap.xml`
4. 对首页和几个核心栏目点"请求编入索引"
5. 记录基线：几天后用 `site:wagwise.org` 看收录条数

> 上线后约 **12 小时内**首页应被收录（craftfee 实测）。每周复测记一次条数。

---

## 阶段 6：IndexNow（加速收录，可选但推荐）

1. 在 `public/` 根放一个 IndexNow 密钥文件（可复用 craftfee 的 key 思路，
   或新生成一个 16 位十六进制 key，文件名就是 key 内容）
2. 在 `public/` 根放 `key.txt`（内容=key）
3. 新页面发布后，向 `api.indexnow.org` 提交 URL 列表（buddy 可写个小脚本复用）

---

## 阶段 7：Email Routing（AdSense 前置，必做）

申请谷歌广告（AdSense）前，必须能收信以验证站点所有权：

1. Cloudflare 开启 **Email Routing**
2. 设 `contact@wagwise.org` → 转发到你的 QQ 邮箱
3. 在隐私权政策页（`/privacy/`）已写明此联系邮箱，保持一致

---

## 阶段 8：Cookie 横幅（已内置，确认即可）

`public/assets/cookie-consent.js` 已实现 Consent Mode v2 默认拒绝，
每页底部会自动出现同意横幅，选择存 12 个月。上线后无需额外操作，
只需确认真站上横幅正常显示。

---

## 上线后养站节奏（参考 craftfee）

- **每 1~2 周加 1~2 个新内页**（新文章 = 新关键词入口 = 新流量）
- **有理由才加**：费率/事实变了、发现新关键词、GSC 出现无对应页面的词
- **GSC 出词后按"四筐法"选题**（有词有页前 10 = 加厚；有词只有擦边页 = 立刻专门写一页；
  有词有页 20 名开外 = 优化旧页；品牌词 = 忽略）
- **不碰权威性主导的大热门词**，专攻长尾细分词（新站权威性弱，硬拼热门必输）
- **现阶段（上线 1 周内）不开第三站**——先把 wagwise 跑成"已验证模板"

## 回滚与排查速查

| 现象 | 处理 |
|---|---|
| 推送总失败 | 确认用了 7890 端口；`git fetch` 验证而非看退出码 |
| 新部署 URL 被"测试实际网址"报 404 | 看 `site:` 条数，不看该工具；查 check-host 全球节点 + DNS |
| canonical 还是占位符 | 重跑 `python set-domain.py wagwise.org` |
| 图片不显示 | 文件名=slug，格式 jpg/png/webp，重跑 `render.py` |
| 想退回本地改 | `python set-domain.py --revert` 然后改完再替换 |
