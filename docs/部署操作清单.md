## 阶段 1：DNS 切到 Cloudflare（逐步操作）

**一句话原理**：域名在 Spaceship 买，但**把"谁来管 DNS"这件事交给 Cloudflare**——
换的不是解析记录，是"名称服务器（Nameserver）"这个更上一级的东西。

### 第 1 步 · 在 Cloudflare 添加站点

1. 登录 Cloudflare 控制台（和 craftfee 同一个账号）
2. 点右上角 **Add a site / 添加站点**
3. 输入 **`wagwise.org`** → 选 **Free 免费计划** → 继续
4. Cloudflare 会"扫描现有 DNS 记录"——**这个域名是全新的、没有任何记录，扫描结果为空是正常的**，直接继续
5. 页面会给你**两个名称服务器地址**，例如：

   | 你的账号大概率是（以页面显示为准） |
   |---|
   | `tara.ns.cloudflare.com` |
   | `viddy.ns.cloudflare.com` |

   （craftfee.com 用的就是这两个——Cloudflare 按**账号**分配 NS，所以很可能相同）
6. **把这两个地址复制下来，页面先别关**

### 第 2 步 · 回 Spaceship 改 Nameserver

1. 登录 Spaceship → **Launchpad / Domain Manager（域名管理器）**
2. 在域名列表里找到 **wagwise.org**，点进去打开设置面板
3. 右侧点 **Nameservers & DNS（名称服务器和 DNS）**
4. 当前显示的是 Spaceship 默认的 `launch1.spaceship.net` / `launch2.spaceship.net`
   → 点右边的 **Change（更改）**
5. 弹窗里选 **Custom nameservers（自定义名称服务器）**
6. 把 Cloudflare 那两个地址**原样粘进去**（两行，一行一个）
7. 点 **Save nameserver settings（保存 DNS 设置）**
8. 会弹二次确认（提示改 NS 可能影响邮件转发等服务）→ 点
   **Yes, change to Custom DNS**

> ⚠️ **不要在 Spaceship 里自己加 A 记录 / CNAME**。NS 一换，Spaceship 的 DNS 面板就失效了，
> 以后所有解析都在 Cloudflare 里配。网站要用的 A 记录也**不用手工加**——
> 等绑 Custom Domain 时 Cloudflare 会自动建（见阶段 4）。

### 第 3 步 · 等 Cloudflare 检测通过

1. 回 Cloudflare 那个页面，点 **立即检查名称服务器 / Check nameservers now**
   （**短时间只能点一次**，别反复点）
2. 等状态从"待处理"变成 **Active（活动）**
   - 快则 **10–15 分钟**，一般 1 小时内，最慢 24–48 小时
   - 成功会收到 Cloudflare 邮件
3. **验收命令**（本地执行，应返回 Cloudflare 那两个 NS）：

   ```sh
   nslookup -type=NS wagwise.org 8.8.8.8
   ```

   或走代理查：

   ```sh
   curl -s -x http://127.0.0.1:7890 -H "accept: application/dns-json" \
     "https://cloudflare-dns.com/dns-query?name=wagwise.org&type=NS"
   ```

## 附 A：社媒分享图（og:image）—— 改图必须换文件名

- 当前图：`public/assets/og-image-wagwise.png`（1200×630），选 PNG 不选 SVG 的原因：
  **微信 / Facebook / X 的爬虫不渲染 SVG**，用 SVG 等于分享出去是空卡片
- 生成方式：`node build/render_og.js`（sharp 渲染）
- ⚠️ **上线后要换这张图，必须换文件名**（例如改成 `og-image-wagwise-2.png`），
  并同步改 `build/render.py` 里 3 处引用（`og:image` / `twitter:image` / Organization logo）
  + 重跑 `render.py`。
  **原因**：`/assets/*` 被设成 `immutable` 缓存一年，而社媒爬虫按 URL 缓存、
  对 `?v=` 无效——同文件名换图片，分享出去还是旧图，一年不变。

## 附 B：改 JS / CSS 必须 bump 版本号

同样因为 `/assets/*` 是一年强缓存：改完 `style.css` 或 `cookie-consent.js`，
必须把引用处的 `?v=N` 加一（当前 `style.css?v=2`），否则老访客拿不到新样式。

- **每 1~2 周加 1~2 个新内页**（新文章 = 新关键词入口 = 新流量）
