# 宠物养护站 · 本地使用说明

本说明给你（朱朱）看，告诉你**不买域名、不联网**也能在电脑上把整个网站看一遍、改内容、换图片。

---

## 一、目录结构（看懂即可，不用记）

```
pet-care-site/
├── build/
│   ├── articles.py        ← 站点全部文字内容（19 篇文章 + 6 个栏目 + 首页/About/Privacy）
│   ├── render.py          ← 把 articles.py 生成成网页（你不用动它）
│   └── gen_placeholders.py← 自动生成"占位图"（你不用动它）
├── public/                ← 生成出来的真正网站（浏览器看的、将来上线用的都在这）
│   ├── index.html         ← 首页
│   ├── dog-training/ ...   ← 各栏目和文章
│   └── assets/img/         ← 文章配图（现在是占位 SVG，将来换成真照片）
├── set-domain.py          ← 买好域名后一键把占位符换成真域名
├── wrangler.jsonc         ← 部署配置（上线用）
├── start-preview.bat      ← Windows 一键本地预览
├── start-preview.sh       ← Mac/Linux 一键本地预览
└── docs/                  ← 这份说明 + 图片替换指南 + 部署清单
```

**核心原则**：你平时只动 `build/articles.py`（改文字）和 `public/assets/img/`（换图）。
改完跑一下"重新生成"命令，网站就更新了。其它文件别动。

---

## 二、本地预览网站（看效果）

### Windows（双击即可）
双击 `pet-care-site\start-preview.bat`，会自动打开浏览器到
`http://127.0.0.1:8787/`。

> 如果没自动打开，手动在浏览器地址栏输入 `http://127.0.0.1:8787/` 回车。

### Mac / Linux
在终端里进入 `pet-care-site` 目录，运行：
```sh
sh start-preview.sh
```
然后浏览器打开 `http://127.0.0.1:8787/`。

预览时所有链接、栏目、文章都能点。域名显示的是 `your-domain.com`（占位符），
这是正常的——还没买域名，上线时会被自动替换。

## 三、改内容（改文字）

所有文章、栏目、首页文案都写在 `build/articles.py` 里。
**改完必须重新生成网页**，否则浏览器看不到变化。

1. 用记事本 / VS Code 打开 `build/articles.py`
2. 找到要改的标题、段落、FAQ（每个文章是一个带 `"slug"` 的块）
3. 保存文件
4. 重新生成（在 `pet-care-site` 目录下）：
   ```sh
   python build/render.py
   ```
5. 刷新浏览器预览即可看到新内容

> 加新文章：在 `articles.py` 的 `ARTICLES` 列表里照着已有的格式加一段，
> 同时在对应栏目的 `links` 里加上它的 slug，再跑 `render.py` 和
> `gen_placeholders.py`，最后按《图片替换指南》放图。

---

## 四、换图（见《图片替换指南.md》）

占位图现在是 SVG（带标题的灰色图，写着"PLACEHOLDER 替换成真照片"）。
你拍/找的高清宠物照片，按文件名丢进 `public/assets/img/`，重新生成即可。

---

## 五、改完想恢复占位图

把 `public/assets/img/` 里你放的真照片删掉，再跑一次 `python build/render.py`，
就会自动回到占位 SVG。

---

## 六、常见问题

- **预览打不开 / 端口被占用**：关掉之前开的预览窗口（或重启电脑），再双击 bat。
- **改了 articles.py 但网页没变**：一定是忘了跑 `python build/render.py`。
- **图片不显示**：确认照片文件名是 `<slug>.jpg`（slug 和文章一一对应，
  可在 articles.py 里搜 `"slug":` 找到每个文章的名字）。
- **本地一切正常，但显示 your-domain.com**：这是占位符，没买域名前都这样，
  买好后按《部署操作清单》一键替换。
