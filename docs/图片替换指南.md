# 宠物养护站 · 图片替换指南（给朱朱）

现在每篇文章默认显示一张**占位图**（灰色、带标题、写着"PLACEHOLDER 替换成真照片"）。
等你拍好 / 找好高清宠物照片，按下面步骤换成真图。**不用改任何代码。**

---

## 一、照片命名规则（最关键）

每张照片的文件名必须和文章的 `slug`（文章编号）一模一样。
`slug` 在 `build/articles.py` 里，每个文章块的第一个字段就是。例如：

| 文章 | slug（照片文件名） |
|---|---|
| 如何笼养训练小狗 | `how-to-crate-train-a-puppy.jpg` |
| 小狗呕吐原因 | `dog-vomiting-causes.jpg` |
| 猫乱抓家具怎么办 | `cat-scratching-furniture.jpg` |
| 最佳狗笼推荐 | `best-dog-crate.jpg` |

完整 19 个 slug 见文末清单。

**支持的格式**：`.jpg`、`.jpeg`、`.png`、`.webp`（推荐 `.jpg` 或 `.webp`，体积小加载快）。

---

## 二、放图步骤

1. 把照片重命名成 `<slug>.jpg`（例如 `how-to-crate-train-a-puppy.jpg`）
2. 复制到 `pet-care-site/public/assets/img/` 目录里（和那一堆 `.svg` 占位图放一起）
3. 在 `pet-care-site` 目录下重新生成网页：
   ```sh
   python build/render.py
   ```
4. 本地预览（`start-preview.bat`）刷新，那篇文章就会显示你的真照片了

> 原理：系统会自动优先用 `<slug>.jpg`，找不到才用 `<slug>.svg` 占位图。
> 所以你放一张真图、跑一次命令就切换了；把真图删掉再跑一次，又回到占位图。

---

## 三、照片要求（影响谷歌排名和颜值）

- **尺寸**：横图优先，建议 **1200×800 以上**（16:9 左右），最小不低于 800 宽。
- **体积**：单张尽量 **< 200KB**（可用微信/美图秀秀压缩，或存成 webp）。
- **内容**：和文章主题强相关（讲笼养就放小狗在笼里的图，讲猫砂就放猫砂盆图）。
- **版权**：必须是你拍的或买的、**可商用**的图。别直接用网上随便搜的图，
  避免版权投诉（谷歌也会降权）。
- **真人宠物优先**：原创实拍最有竞争力，和你的"艺术乌托邦"原创路线一致。

---

## 四、一次放多张 / 放错想撤

- 可以一次放好几张（每张按 slug 命名），放完跑一次 `render.py` 全部生效。
- 放错了：删掉那个 `.jpg` 文件，重跑 `render.py`，该文章回到占位图。
- **不要删 `.svg` 占位图**——它们是"没有真图时的兜底"，留着没坏处。
