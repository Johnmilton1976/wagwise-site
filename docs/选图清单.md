> 用途：朱朱按「图片文件名」命名高清图，丢进 `pet-care-site/public/assets/img/` 即可。
> 系统已写好「自动探测真图」——有 `.jpg` 就用真图，没有就显示占位图，不用改任何代码。

## 图片要求
- 格式：`.jpg` 或 `.webp`（优先用 `.jpg`）
- 尺寸：横图 16:9，宽 ≥ 1200px（展示为 16:9 圆角，竖图会被裁切）
- 来源：自己的宠物照最好；没有就用免费 CC0 图库 Unsplash / Pexels / Pixabay（搜英文关键词）
- 数量：每篇 1 张主图；交几张换几张，没交的自动显示占位图，不影响上线

## 操作流程
1. 按上表文件名存好图（如 `how-to-crate-train-a-puppy.jpg`）
2. 全部丢进 `pet-care-site/public/assets/img/` 目录
3. 告诉 buddy「图放好了」，buddy 跑 `python build/render.py` 一键换图（或直接你自己跑）
4. 本地预览 `http://127.0.0.1:8787/` 确认真图已显示

> 注：占位图已带标题文字，临时上线用占位图也完全没问题，真图可随时补。
