# WagWise Pet

A static SEO content site for dog & cat care — guides, care advice, and a dog-age calculator, written for pet owners searching on Google.

- **Content**: 6 pillar hubs + 30+ articles + a dog-age calculator tool.
- **Stack**: Pure static HTML generated by a small Python builder (`build/render.py` + `build/articles.py`); images optimized with `sharp` (`build/apply_photos.js`).
- **Hosting**: Deployed to Cloudflare Workers/Pages; domain `wagwise.org`.

## Local preview
```bash
cd public
python -m http.server 8787
# open http://127.0.0.1:8787/
```

## Regenerate the site
```bash
python build/render.py
```

## Project layout
- `build/` — generators and content data
- `public/` — the static site (this is what gets deployed)
- `docs/` — internal notes and checklists

This is a content/SEO project, not a traditional web app: each article is a traffic entry point, and new articles are added every 1–2 weeks to grow keyword coverage.
